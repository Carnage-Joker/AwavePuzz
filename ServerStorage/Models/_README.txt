This directory should contain weapon models and other game assets.

Required Weapon Models:
- Pistol.rbxm - Starting weapon model
- SMG.rbxm - Submachine gun model
- Shotgun.rbxm - Shotgun model
- Rifle.rbxm - Rifle model
- AssaultRifle.rbxm - Assault rifle model

Each weapon model should include:
- Handle part for attachment
- Muzzle attachment point (for effects)
- Barrel end point (for raycast origin)
- Sight attachment point (for ADS)

Other Models:
- CureStation.rbxm - Puzzle interaction station
- ResourcePickup.rbxm - Cure component pickup model
