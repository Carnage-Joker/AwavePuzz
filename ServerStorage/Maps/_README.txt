This directory should contain map models for the game.

Each map should be a Model with:
- ZombieSpawnPoints (Folder containing Part instances)
- ResourceSpawnPoints (Folder containing Part instances)
- Terrain and structures
- Lighting configuration
- Optional: CureStations (Folder with interaction points)

Example Maps:
- ResearchFacility.rbxm
- DesertOutpost.rbxm
- UrbanRuins.rbxm

The game will use Workspace-based spawn points if no maps are provided.
