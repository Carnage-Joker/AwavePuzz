# Archive Documentation

This directory contains historical documentation that is no longer actively maintained but preserved for reference.

## Directory Structure

### `/fixes/`
Historical bug fix and stabilization reports:
- Ammo display fixes
- Boot stabilization implementations
- Touch control improvements
- UI audit implementations
- Various bugfix reports

These documents track specific issues that were resolved during development. They are kept for historical reference and understanding the evolution of the codebase.

### `/summaries/`
Implementation summaries and project milestones:
- Feature implementation summaries (portal matchmaking, alliances, etc.)
- AI system changes and testing guides
- Player spawn system documentation
- Historical consolidation reports
- Documentation from `docs/summaries/` (reorganization, convergence, GUI improvements, etc.)

### `/reviews/`
Code reviews and project assessments:
- Code review summaries
- Project reviews
- Duplicate cleanup reports

### `/reports/`
General project reports and audits:
- Executive summaries
- System diagrams
- Risk registers
- Implementation summaries
- Verification reports
- Bug tracking
- Improvement plans

## Usage

These documents are **archived** and may reference:
- Old code structures (e.g., `src/` directory that no longer exists)
- Features that have been replaced or refactored
- Historical implementation details

For current documentation, please refer to:
- [README.md](../../README.md) - Project overview
- [INSTALLATION.md](../../INSTALLATION.md) - Setup guide
- [DOCUMENTATION.md](../../DOCUMENTATION.md) - Complete documentation index
- [docs/](../) - Active documentation

## Why Archive?

These documents are preserved because they:
1. Provide context for past development decisions
2. Document the evolution of the codebase
3. May contain useful troubleshooting information
4. Serve as a historical record of the project

However, they are no longer actively maintained and should not be the primary reference for current development work.
