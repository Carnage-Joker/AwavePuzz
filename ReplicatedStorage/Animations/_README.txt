This directory contains placeholder .txt files for weapon animations.

In Roblox Studio, these should be replaced with Animation instances with proper AnimationIds.

Each weapon should have the following animations:
- Idle - Subtle breathing and weapon bob
- Fire - Recoil and muzzle movement
- Reload - Full magazine change sequence
- Equip - Weapon draw animation
- Sprint - Lowered weapon while running
- ADS - Sight alignment animation (Aim Down Sights)
